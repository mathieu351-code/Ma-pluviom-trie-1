# Ma Pluviométrie — V1 web
Application web installable sur Android. Saisie quotidienne de pluie en mm, heure, note, historique, totaux jour/semaine/mois/année et graphique. Les données sont stockées localement dans le navigateur. Aucun GPS.

Pour l'installer comme appli sur Android, héberger les fichiers sur une adresse HTTPS puis ouvrir la page dans Chrome et choisir l'installation / ajout à l'écran d'accueil.
